空间弧垂曲线工具

作者：Mz | 版本：0.24 | 适用 CAD：AutoCAD / GstarCAD / 中望CAD | 项目地址：GitHub

一、软件简介

本工具用于在 AutoCAD、GstarCAD（浩辰 CAD）或中望 CAD（ZWCAD）中快速生成三维空间悬链线（弧垂曲线），并支持两曲线最小距离测量、风偏弧垂曲线、分裂导线、含悬垂绝缘子串的弧垂线绘制，以及在二维平面上按图纸比例绘制断面弧垂曲线。核心计算基于《电力工程设计手册 架空输电线路设计》式14-1 悬链线方程，K 值直接取用物理值，无需换算。

支持功能：

  1. 生成空间弧垂曲线 — 拾取两个悬挂点，输入 K 值，在两点间生成真三维弧垂曲线。
  2. 两条曲线最小距离 — 拾取两条 CAD 曲线，计算并绘制最小距离连线与数值标注。
  3. 风偏弧垂曲线 — 选一条弧垂曲线，输入风偏角，生成绕端点连线旋转的蓝色风偏曲线。
  4. 分裂导线 — 以一条弧垂曲线为中心线，按间距生成双分裂（水平/垂直）或四分裂子导线。
  5. 含悬垂串弧垂线 — 悬挂点可设置悬垂绝缘子串（长度、风偏角），支持带风偏的完整弧垂建模。
  6. 二维断面悬链线（v0.24 新增）— 在二维平面（XY）上按横向/纵向图纸比例绘制 K 值悬链线，支持连续点选多段。

二、环境要求

  • 操作系统：Windows 10 / 11（64 位）
  • CAD 软件：AutoCAD、GstarCAD（浩辰 CAD）或中望 CAD（ZWCAD），64 位版本，不支持 AutoCAD LT；支持一台机器安装多个版本并存（如 AutoCAD 2020 + 2022）
  • 中望 CAD 用户注意：安装时须勾选 COM / ActiveX 支持（中望默认可能不注册 COM），否则本工具无法连接
  • 运行方式：无需安装 Python——GUI 双击 空间弧垂曲线工具.exe；命令行用 空间弧垂曲线工具CLI.exe。也可用 Python 3.12 + pywin32 跑源码 catenary_app.py

三、启动方式

方式一：GUI 图形界面（推荐）

双击 空间弧垂曲线工具.exe 直接运行（免 Python 环境）。源码运行：双击 catenary_app.py（或用 pythonw catenary_app.py 启动，无控制台窗口），弹出操作窗口。

方式二：命令行模式

用 空间弧垂曲线工具CLI.exe（console 版，有控制台输出，跑完正常退出；GUI 版 exe 不提供命令行模式）。也可用源码 python catenary_app.py，效果相同。无参数运行会打印用法帮助。

空间弧垂曲线工具CLI.exe draw --K 15.22 --pick     # 交互拾取两点生成弧垂
空间弧垂曲线工具CLI.exe draw --K 15.22 --p1 0 0 0 --p2 100 30 12   # 直接给坐标
空间弧垂曲线工具CLI.exe mindist --pick            # 交互选两条曲线测距
空间弧垂曲线工具CLI.exe wind --handle E90 --angle 30.6  # 按句柄生成风偏
空间弧垂曲线工具CLI.exe bundle --pick --d 600 --mode quad   # 四分裂 600mm
空间弧垂曲线工具CLI.exe suspension --K 15.22 --pick --s1 --d1 3 --s2 --d2 4 --wind --b 20  # 含悬垂串+风偏
空间弧垂曲线工具CLI.exe draw2d --K 15.22 --pick              # 二维断面：连续点选（ESC/右键结束）
空间弧垂曲线工具CLI.exe draw2d --K 15.22 --p1 0 0 --p2 60 10 --rx 5000 --ry 500  # 二维断面：给定图上两点+比例
💡 在 Windows 控制台（GBK 编码）下，输出中的 ✔ ✘ 等符号会显示为 ?，属正常容错表现，不影响结果。

四、角度正负约定（重要）

💡 所有角度（风偏角、串角 A、线偏角 B）统一约定：右偏为正（+）、左偏为负（−）。"左右"以点选先后顺序为前进方向——面向第 1 点→第 2 点方向观察，右手边即为"右"。

五、GUI 功能详解

连接 CAD

启动后首先需要连接 CAD：

  • 目标下拉：自动 / AutoCAD / GstarCAD / 中望CAD。选择「自动」时程序会识别你当前正在操作的 CAD 窗口。
  • 点击「连接/刷新 CAD窗口」，状态栏显示连接结果（如「已连接 AutoCAD Drawing1」）。图纸名很长时窗口会自动加宽以完整显示，右侧按钮不会被挤掉。
  • 多实例自动识别（v0.24 增强）：工具会枚举本机所有版本的 AutoCAD / GstarCAD / 中望CAD，并分别识别同一 CAD 的每一个运行实例（如 AutoCAD 2020 与 2026 同时打开），按你当前操作的窗口精确连接对应版本。优先连接已运行的实例（秒级响应），全部未开启才自动启动。
  • 跟随重连：目标选「自动」时，每次操作前会重新判定前台 CAD 实例——你切了窗口（哪怕只是切到另一个 AutoCAD 版本）直接点功能按钮即可，程序会自动跟随重连（日志打印「→ 前台已切到 xxx，跟随重连…」）。若把下拉固定成某个 CAD，则按你的选择走、不跟随。
  • CAD 必须已启动并打开了图纸，否则连接失败；已连接但无图纸时工具会自动新建一张。
  • 若连接失败，可点击「诊断 CAD」查看本机注册状态；或在 CLI 运行 空间弧垂曲线工具CLI.exe check。
💡 如果同时开着多个 CAD（如 AutoCAD + 中望CAD + 同族多版本），选「自动」会连你刚在操作的那个；也可直接在下拉中指定某个 CAD 种类。

① 生成空间弧垂曲线

「输入方式」下拉提供两种等价选项，按需选择：

选项输入说明
K值K（省略 10⁻⁵）直接填 K，如 15.22
应力+比载σ₀(N/mm²) + γ(N/(m·mm²))程序内部换算 K=γ/(8σ₀)

两种输入方式均用同一算法：悬链线方程 y = a·cosh((x−x₀)/a) + y₀（a = 1/(8K)），不等高时用牛顿迭代精确求解最低点偏移 x₀。

  1. 选择输入方式并填入参数，以及采样点数。
  2. 点击「拾取两点并生成」— 窗口自动最小化，切换到 CAD。
  3. 在 CAD 命令行/十字光标下依次点选两个悬挂点（三维点）。
  4. 窗口恢复，曲线已生成（图层"悬链线"，红色）。
⚠️ 弧垂方向为 Z 轴（竖直方向）。确保在 CAD 中 Z 轴指向天空。

② 两条曲线最小距离

  1. 点击「依次拾取两条曲线」→ 窗口最小化。
  2. 在 CAD 中依次点选第一条曲线、第二条曲线（支持直线/圆弧/圆/多段线/样条曲线）。
  3. 程序自动计算并绘制绿色最小距离连线，标注实测距离值。

③ 风偏弧垂曲线

  1. 输入风偏角（度，右偏为正、左偏为负，见"四、角度正负约定"）。
  2. 点击「拾取曲线并生成」→ 窗口最小化。
  3. 在 CAD 中点选一条已生成的弧垂曲线。
  4. 生成蓝色风偏曲线（图层"风偏弧垂曲线"），原曲线保持不变。

风偏曲线是原曲线绕首尾端点连线旋转指定角度而成。标签显示「风偏X°」，均为绝对值（忽略输入正负号）。

④ 分裂导线

  1. 输入分裂间距（单位 mm），如 600 表示图上 0.6m。
  2. 选择模式：水平双分裂 / 垂直双分裂 / 四分裂。
  3. 点击「拾取中心线并生成」→ 在 CAD 中点选一条弧垂曲线（可为风偏后的曲线）。
  4. 生成黄色子导线（图层"分裂导线"），中心线保持不变。

几何原理：分裂方向基于"弦平面局部坐标系"——水平分裂沿平面法线 n、垂直分裂沿平面内垂直弦方向 v、四分裂为两者四角组合。风偏后的倾斜曲线同样适用，子导线处处与中心线平行、间距恒为 d。

⑤ 含悬垂串弧垂线

「输入方式」与模块①一致，两种等价选项：K值（K 省略 10⁻⁵）/ 应力+比载（σ₀ + γ，程序算 K=γ/(8σ₀)），均用同一悬链线算法（cosh + 牛顿迭代）。

  1. 选择输入方式并填入参数、采样点数。
  2. 勾选「点1悬垂串」「点2悬垂串」，输入各自串长 D（单位 m）；不勾选则该点为普通悬挂点。
  3. 未勾选「绘制风偏线」：串角按 0（竖直串），画品红悬垂串 + 红色基准弧垂线。
  4. 勾选「绘制风偏线」：输入线偏角 B(°)、串角 A1/A2(°)（右偏为正）：
    • 悬垂串按 A 摇摆 → 绘制浅蓝色摆串（图层"悬垂串风偏"）；
    • 直接绘制蓝色风偏线（以摆串下端为端点）；
    • 不再绘制未风偏的参照曲线与参照绝缘子（只画风偏相关元素）。
  5. 点击「拾取两点并生成」→ 在 CAD 中依次点选两个悬挂点（顺序 = 前进方向）。

⑥ 二维断面悬链线（断面图）

用于纵断面图：在二维平面（XY）上画 K 值悬链线。与模块①的区别是——①画的是真三维空间曲线（取两点的 X/Y/Z 三轴），⑥画的是二维平面曲线（只取 X、Y，拾取点的 Z 被忽略），并且带图纸比例。

输入默认说明
K 值（省略 10⁻⁵）15.22只支持 K 值输入，不做「应力+比载」
图纸比例 · 横向5000横向（X，档距方向）出图比例分母
图纸比例 · 纵向500纵向（Y，高程方向）出图比例分母
采样点数200与模块①共用同一输入框
「拾取挂线点并生成」—点击后在 CAD 中连续点选挂线点（见下）

比例是什么意思

前提：图纸 1 绘图单位 = 1 mm，实际工程尺寸用 m。程序先按比例把图上坐标反算成实际米数，用 K 值算出真实悬链线，再按比例缩放回图纸坐标画出来：

图上坐标 = 实际坐标 × 1000 ÷ 比例分母

横向 1:5000 → 图上 1mm 代表实际 5000mm = 5m → 图上 = 实际 × 1000/5000 = ×0.2  （即你说的 1/5）
纵向 1:500  → 图上 1mm 代表实际  500mm = 0.5m → 图上 = 实际 × 1000/500  = ×2.0  （即你说的 2 倍）
💡 为什么必须"先反算再缩放"：K 值（1/m）只有作用在实际档距上才有物理意义。若直接拿图上坐标当米用，档距会被缩小 5 倍，画出来的线几乎成了直线——输入 K 值这个动作就白做了。因为反算与缩放互为逆运算，所以曲线两端会精确落在你点的两个点上，中间按真实 K 值下垂。

连续点选（v0.24）

  1. 点击「拾取两点并生成」— 窗口自动最小化，切换到 CAD。
  2. 点第 1 点（起点）、点第 2 点 → 立即生成第 1 段曲线（1-2）。
  3. 不退出：继续点第 3 点 → 以第 2 点（上一段终点）为起点生成第 2 段曲线（2-3）；点第 4 点 → 生成 3-4 段……可一直连下去。K 值与比例全程相同。
  4. 按 ESC 或鼠标右键结束连续点选（已生成的段全部保留）。
💡 若某一段的起点与终点 X 相同（两点在图上水平投影重合，无法确定档距方向），该段会自动跳过并提示，不影响后续继续点选。若取点过程出现异常，也会结束连续点选并保留已画曲线，不会丢结果。

输出：红色二维多段线，图层「悬链线」，画在 Z=0 平面；不自动缩放视图（断面图通常已有整幅图框，自动 ZoomExtents 会打断视图）。生成后可继续用模块②量取与其它曲线的最小距离。

七、常见问题

Q: 连接失败 / 无法连接 CAD

先点击「诊断 CAD」按钮（或运行 空间弧垂曲线工具CLI.exe check）查看本机 COM 注册状态：

  • 提示"CAD 未注册 / 无效的类字符串"（-2147221005）：本机注册表里没有对应 CAD 的 COM 项。常见原因：未安装 CAD、绿色版未注册、或用了 32 位 Python；中望 CAD 还可能是安装时未勾选 COM/ActiveX 支持（需重新安装并勾选）。请确认 CAD 已完整安装；已安装但仍报错时，用 64 位 Python 运行。
  • 提示"需要管理员权限"（-2147024156）：CAD 与工具的进程权限不一致（通常 CAD 以管理员运行而工具没有）。本版本会自动检测并处理：GUI 弹窗询问是否以管理员身份重启，CLI 自动弹 UAC 提权；若提权被拒绝，也可手动右键 exe →“以管理员身份运行”，或右键 CAD 快捷方式 → 属性 → 兼容性 → 取消勾选「以管理员身份运行此程序」后重启 CAD。
  • 装了两个 AutoCAD 版本（如 2020 + 2022），连接慢或连不上：v0.22 起支持多版本共存，自动枚举所有版本并优先连接已运行的实例（秒级响应，不会误启动另一个版本）。请确认使用 v0.22 及以上版本。
  • 中望 CAD 能连吗：可以（v0.23 起）。中望提供标准 COM 接口（ZWCAD.Application），连接 / 绘图 / 交互拾取均已验证可用。若提示"未注册"，多半是安装时未勾选 COM/ActiveX 支持；可在 CLI 运行 check 确认「中望CAD: 已注册」。
  • 其他情况：确保 CAD 已启动并打开图纸；在 GUI 中确认「目标」下拉选对了 CAD 或「自动」。多个 CAD 同时开时建议用「自动」或手动指定。

Q: 点选时没反应 / 报错

点选操作是在 CAD 的命令行进行的，不是在 Python 窗口。程序会最小化 GUI 窗口，此时应在 CAD 中操作。若误点取消（ESC），程序会提示"已取消"。

Q: 生成的曲线看不到 / 太小

弧垂在短档距下很小。例如 K=15、档距 100m → 弧垂约 1.5m；档距 300m → 弧垂约 13m。程序会自动 ZoomExtents，若仍看不见，检查 K 值和档距是否合理。

Q: 风偏曲线与原曲线重合

当输入角度为 0° 时无偏转，生成曲线与原曲线重合。输入非零角度即可。

Q: K 值和应力+比载输入，为什么结果一样 / 不一样

两种输入是同一曲线的两种表述：只要 σ₀、γ 满足 K=γ/(8σ₀)，画出的就是同一条悬链线（等高与高差大时都一致）；若 σ₀/γ 与 K 不对应（例如切到「应力+比载」时框里残留上次的旧值），结果自然不同。K 值模式同样走悬链线 + 牛顿迭代高差修正（a = 1/(8K)）。

Q: 分裂导线方向不对 / 画歪了

分裂方向基于"弦平面局部坐标系"，风偏后的曲线分裂方向随平面旋转是正确行为（子导线与中心线平行、间距恒为 d）。若觉得"歪"，是风偏场景下的正常几何。

Q: 二维断面（⑥）画出来的弧垂特别小，几乎像直线

先确认两点：① 档距是不是够大——⑥ 会按横向比例把图上档距反算成实际档距，图上 60 单位在 1:5000 下相当于实际 300m，弧垂才明显；若横向比例填得很大（如 1:20000），实际档距变短、弧垂自然小。② 图纸单位是不是 mm——本功能按「图纸 1 绘图单位 = 1 mm」设计；若你的图是按 1:1（单位=米）画的，需要把比例分母相应换算后再填。

Q: 二维断面（⑥）生成后看不到线 / 视图没变化

⑥ 不自动缩放视图（断面图通常已有整幅图框，自动 ZoomExtents 会打断视图）——请手动缩放/平移查看。曲线画在 Z=0 平面（拾取点的 Z 被忽略），若你的图纸工作平面不在 Z=0，或用了旋转的 UCS，请先切回世界坐标系（UCS → 世界）再操作。

Q: 同时开了 AutoCAD 2020 和 2026（或同一 CAD 多个版本），切窗口后画错 CAD

v0.24 起已修复：程序会把同一 CAD 的每个实例都识别出来，并按你当前操作的那个窗口精确连接对应版本。请把「目标」下拉保持为「自动」——每次操作前程序都会重新判定前台实例，切了窗口直接点功能按钮即可（日志会打印「→ 前台已切到 xxx，跟随重连…」）。若把下拉固定成某个 CAD，则不跟随、按你的选择走。

Q: 连接后状态栏的图纸名被截断 / 「连接/刷新」按钮看不全

连接图纸名很长时，窗口会自动加宽（上限 1100px）以完整显示，「连接/刷新 CAD窗口」等按钮始终完整、不会被挤掉；只有名字长到连上限都放不下时，才在中间省略并保留尾部（如 …明细表.dwg ✓）。名字变短后窗口会自动缩回。若仍显示不全，可再点一次「连接/刷新 CAD窗口」。

九、技术说明

  • 悬链线方程：y = a·cosh((x−x₀)/a) + y₀，a = 1/(8K)
  • 弧垂定义：两端连线中点沿 Z 轴竖直向下与曲线交点的距离
  • 曲线类型：AcDb3dPolyline（真三维多段线，Z 不丢失）
  • 风偏旋转：Rodrigues 旋转公式，绕首尾端点连线为轴
  • 分裂导线：弦平面局部坐标（u 弦向 / n 平面法线 / v=n×u），子导线 = 中心线等距平移
  • 悬垂串：下端 = 上端 + right·D·sin(A) − z·D·cos(A)；风偏线 = 摆串端点基准绕弦转 B
  • 二维断面悬链线（⑥）：图上坐标 ↔ 实际米数互换（scale = 1000 ÷ 比例分母），先反算实际档距/高差算 K 值悬链线，再缩放回图纸坐标；曲线类型 AcDbPolyline（二维多段线，Z=0；若目标 CAD 无此接口则自动退化为 AcDb3dPolyline 传 Z=0）
