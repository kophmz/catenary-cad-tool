# 空间弧垂曲线工具

> 作者：Mz | 版本：0.24 | 项目地址：[https://github.com/kophmz/catenary-cad-tool](https://github.com/kophmz/catenary-cad-tool)

基于《电力工程设计手册 架空输电线路设计》K 值公式，在 AutoCAD / GstarCAD / 中望CAD 中生成三维空间悬链线（弧垂曲线），支持测距、风偏曲线、悬垂串绘制，以及在二维平面上按图纸比例绘制断面弧垂曲线。

## 功能

| 序号 | 功能 | 说明 |
|------|------|------|
| ① | 生成空间弧垂曲线 | K 值悬链线，真三维 AcDb3dPolyline，支持不等高悬挂点；支持「K值 / 应力σ₀+比载γ」两种等价输入 |
| ② | 两条曲线最小距离 | 暴力搜索最近点对，绘制绿色最小距离连线与标注 |
| ③ | 风偏弧垂曲线 | 绕首尾端点连线旋转生成蓝色风偏曲线，带角度标签 |
| ④ | 分裂导线 | 沿曲线生成双分裂/四分裂子导线（黄色），间距单位 mm，随风偏平面旋转 |
| ⑤ | 含悬垂串弧垂线 | 悬挂点可设悬垂绝缘子串（长度、风偏角）；风偏模式只画风偏线+摆串（不画未风偏参照）；K 输入方式同①（K值 / 应力+比载） |
| ⑥ | 二维断面悬链线 | 在二维平面（XY）画 K 值悬链线，带**横向/纵向图纸比例**（默认 1:5000 / 1:500）；**支持连续点选**——每点一个挂点即生成一段，可一路连下去；曲线保证包含**弧垂最低点**（在档外则自动延伸），并画**倒三角最低点标记** |

## 环境要求

- **操作系统**：Windows 10 / 11（64 位）
- **CAD**：AutoCAD、GstarCAD（浩辰 CAD）或中望 CAD（ZWCAD），须为 64 位版本；不支持 AutoCAD LT；支持一台机器安装多个版本并存（如 AutoCAD 2020 + 2022）
- **中望 CAD 用户注意**：安装时需勾选 **COM / ActiveX 支持**（中望默认可能不注册 COM），否则本工具无法连接
- **无需安装 Python**：已打包为独立 .exe

## 快速开始

### 方式一：双击 .exe（GUI）

直接双击 `空间弧垂曲线工具.exe`，弹出窗口：

1. 点击「连接/刷新 CAD窗口」连接 CAD（自动识别本机所有版本的 AutoCAD / GstarCAD / 中望CAD，**优先连接已运行的实例，秒级响应**；全部未开启才自动启动）
2. 连接失败时可点击「诊断 CAD」按钮查看本机 COM 注册状态，自助定位问题
3. 选择功能模块，按提示在 CAD 中拾取点/曲线

### 方式二：命令行（CLI）

用 `空间弧垂曲线工具CLI.exe`（console 版，有控制台输出，跑完正常退出；GUI 版 exe 不提供命令行模式）：

```bash
# 交互拾取两点生成弧垂
空间弧垂曲线工具CLI.exe draw --K 15.22 --pick

# 直接给坐标
空间弧垂曲线工具CLI.exe draw --K 15.22 --p1 0 0 0 --p2 120 30 12

# 选两条曲线测距
空间弧垂曲线工具CLI.exe mindist --pick

# 按句柄生成风偏曲线
空间弧垂曲线工具CLI.exe wind --handle E90 --angle 30.6

# 含悬垂串弧垂线（用 σ₀+γ 输入，K = γ/(8σ₀)）
空间弧垂曲线工具CLI.exe suspension --sigma 50 --gamma 0.06088 --pick --s1 --d1 3 --s2 --d2 4 --wind --b 20

# 二维断面悬链线：连续点选（每点一次生成一段，ESC/右键结束）
空间弧垂曲线工具CLI.exe draw2d --K 15.22 --pick

# 二维断面悬链线：直接给图上两点坐标（二维 X Y）+ 自定义比例
空间弧垂曲线工具CLI.exe draw2d --K 15.22 --p1 0 0 --p2 60 10 --rx 5000 --ry 500
```

> 无参数运行 `空间弧垂曲线工具CLI.exe` 会打印用法帮助。也可用源码 `python catenary_app.py <子命令> ...`（效果相同）。运行 `空间弧垂曲线工具CLI.exe check` 可查看本机 CAD 注册状态。

## v0.24 更新内容

- **新增「⑥ 二维断面悬链线」**：在二维平面（XY）上画 K 值悬链线，用于纵断面图。
- **图纸比例参数**（横向默认 1:5000、纵向默认 1:500）：程序先按比例**反算实际尺寸**（档距、高差换算成米），用 K 值算出真实悬链线，再按比例缩放回图纸坐标。这样 K 值才有物理意义——否则拿图上坐标当米用，档距被缩小 5 倍，画出来的线几乎成了直线。
  - 换算关系：`图上坐标 = 实际坐标 × 1000 ÷ 比例分母`。图纸 1 绘图单位 = 1 mm 时，横向 1:5000 ⇒ 图上 1mm = 实际 5m（图上 = 实际 × 1/5）；纵向 1:500 ⇒ 图上 1mm = 实际 0.5m（图上 = 实际 × 2）。
- **连续点选**：点第 1、2 点生成第 1 段后不退出，继续点第 3 点即以「上一段终点」为新起点生成「2-3」段，可一直连下去；K 值与比例全程相同，ESC / 右键结束。端点不合法（如两点 X 相同）的段自动跳过并提示，不影响后续点选。
- **弧垂最低点**：曲线保证包含最低点——若最低点落在两挂点档距之外（大高差时会发生），自动把曲线延伸过去；并在最低点上方画一个**倒三角标记**（顶点＝最低点，底边在上）。标记尺寸按实际尺寸恒定、随图纸比例缩放（如 1:5000/1:500 时为顶边 2×高 2 图纸单位，比例改到 1:2500/1:250 则变 4×4）。
- **二维 Y = 高程**：点选点的 X 为档距方向、Y 为高程方向（即原三维的 Z 转为二维的 Y），拾取点的 Z 被忽略，曲线画在 Z=0 平面。
- **API**：新增 `catenary_section_2d()`（纯算法，`catenary_core.py`）、`draw_catenary_2d()` 与 `draw_low_point_marker()`（绘图，`catenary_cad.py`；前者主用二维多段线 `AddLightWeightPolyline`，不支持时自动退化为三维多段线 Z=0）。
- **多实例 CAD 精确识别与连接（修复）**：以前「同一个 CAD 装了两个版本且同时打开」时（如 AutoCAD 2020 + 2026），只有其中一个实例能被发现，切到另一个窗口会连错 CAD。现在：
  - 检测阶段**收集同一 CAD 的全部实例**（按窗口句柄去重），并把「能产出该窗口的 ProgID」一并带出；
  - 「自动」模式下按 Z 序判定你正在操作的那个窗口，**用产出它的那个 ProgID 精确连接**——所以切到 AutoCAD 2026 就画进 2026，切到 2020 就画进 2020；
  - 每次操作前比对一次前台实例，**切了窗口就自动跟随重连**（先连成功才替换，失败保留原连接、不打扰你）；
  - 精确定位失败时自动回退到常规候选顺序，不会因此完全连不上。
  - 「目标」下拉固定指定某个 CAD 时不做跟随，按你的选择走。
- **连接栏宽度自适应**：连接后状态栏会显示「已连接 xxx 图纸名.dwg」，图纸名很长时窗口会**自动加宽**（上限 1100px）以完整显示；确实放不下才在中间省略并保留尾部（如 `.dwg ✓`）。右侧「连接/刷新 CAD窗口」等按钮**永远不会被长名字挤掉**，名字变短后窗口自动缩回。
- ⑥ 输入行按「K 值 / **图纸比例**（横向、纵向）/ 采样点数 / 拾取挂线点并生成」排布，说明栏按句分行（不出现句子中间断行）。
- 不改变①~⑤ 的任何行为。

- **自动新建图纸**：CAD 已连接但未打开图纸时自动新建，不再报"无图纸"。

## K 值说明

K 值 = γ/(8σ)，单位 1/m，输入时省略 10⁻⁵ 后缀（如 `15.22` = 15.22×10⁻⁵）。

**公式**：悬链线 y = a·cosh((x−x₀)/a) + y₀，a = 1/(8K)。不等高时牛顿法精确求解最低点偏移 x₀（内置高差修正）。

模块①与⑤「输入方式」两选项（等价，均用 cosh + 牛顿迭代求解）：
- **K值**：直接填 K（省略 10⁻⁵）
- **应力+比载**：填 σ₀(N/mm²)、γ(N/(m·mm²))，程序算 K=γ/(8σ₀)

## 命令行参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `--K` | K 值（省略 10⁻⁵） | `--K 15.22` |
| `--sigma` | 导线应力 σ₀(N/mm²) | `--sigma 50` |
| `--gamma` | 导线比载 γ(N/(m·mm²)) | `--gamma 0.06088` |
| `--n` | 采样点数，默认 200 | `--n 500` |
| `--p1 / --p2` | 悬挂点坐标 `x y z`（`draw` / `suspension`）；**`draw2d` 为二维 `x y`** | `--p1 0 0 0 --p2 100 30 12` |
| `--pick` | CAD 中交互拾取 | `--pick` |
| `--handle` | 按句柄指定图元（16 进制） | `--handle E90` |
| `--angle` | 风偏角（度） | `--angle 30.6` |
| `--rx / --ry` | 仅 `draw2d`：横向 / 纵向图纸比例分母，默认 5000 / 500 | `--rx 5000 --ry 500` |
| `--layer` | 仅 `draw2d`：输出图层名，默认「悬链线」 | `--layer 悬链线` |
| `--cad` | 强制指定 CAD（`autocad` / `gstar` / `zwcad`） | `--cad zwcad` |

## 常见问题

**Q: K 值和应力+比载输入，为什么结果一样 / 不一样？** — 两种输入是同一曲线的两种表述：只要 σ₀、γ 满足 K=γ/(8σ₀)，画出的就是同一条悬链线（等高与高差大时都一致）；若 σ₀/γ 与 K 不对应（例如切到「应力+比载」时框里残留上次的旧值），结果自然不同。K 值模式同样走悬链线 + 牛顿迭代高差修正（a = 1/(8K)）。

**Q: 连接失败，提示“CAD 未注册 / 无效的类字符串”** — 本机注册表里没有对应 CAD 的 COM 项。常见原因：未安装 CAD、绿色版未注册、或使用了 32 位 Python；**中望 CAD 还可能是安装时未勾选 COM/ActiveX 支持**（需重新安装并勾选）。可点击 GUI 的「诊断 CAD」按钮，或在 CLI 运行 `空间弧垂曲线工具CLI.exe check` 查看本机注册状态。

**Q: 装了两个 AutoCAD 版本（如 2020 和 2026）并同时打开，连接慢或连不上？** — v0.24 起已完整支持：工具会**分别发现每一个实例**，并按你当前操作的窗口精确连接对应版本（切到 2026 就画进 2026，切回 2020 就画进 2020），无需关掉任何一个版本。请使用 v0.24 及以上版本；连接前可先点「诊断 CAD」确认本机注册状态。

**Q: 切到另一个 CAD 窗口后，图形画进了错误的 CAD？** — 「目标」下拉保持「自动」即可：每次操作前工具会重新判定前台 CAD 实例，切了窗口会自动跟随重连（日志会打印「→ 前台已切到 xxx，跟随重连…」）。若把下拉固定成了某一个 CAD，则不跟随、按你的选择走。仍不对时可点一下「连接/刷新 CAD窗口」。

**Q: 连接失败，提示“需要管理员权限 / 请求的操作需要提升”** — CAD 与工具进程权限不一致（通常 CAD 以管理员运行而工具没有）。本版本会自动检测并处理：GUI 弹窗询问是否以管理员身份重启，CLI 自动弹 UAC 提权；若提权被拒绝，也可手动右键 exe →“以管理员身份运行”，或右键 CAD 快捷方式 → 属性 → 兼容性 → 取消勾选「以管理员身份运行此程序」后重启 CAD。

**Q: 连接失败（其他情况）** — 确保 CAD 已启动并打开图纸；多个 CAD 同时开时选用「自动」或手动指定。仍失败时点击「诊断 CAD」或在 CLI 运行 `check` 查看注册状态，按提示排查。

**Q: 中望 CAD 能连吗？** — 可以（v0.23 起）。中望 CAD 提供标准 COM 接口（`ZWCAD.Application`），本工具的连接 / 绘图 / 交互拾取均已验证可用。若提示"未注册"，多半是安装时未勾选 COM/ActiveX 支持，重新安装并勾选即可；可在 CLI 运行 `check` 确认「中望CAD: 已注册」。

**Q: 点选没反应** — 提示在 CAD 命令行，不在 Python 窗口。程序会最小化 GUI → 在 CAD 中操作 → 窗口自动恢复。

**Q: 弧垂太小看不到** — K=15、档距 100m → 弧垂约 1.5m；档距 300m → 约 13m。程序自动 ZoomExtents。

**Q: 32 位 CAD 兼容吗** — 不支持。打包的 exe 是 64 位。

**Q: AutoCAD LT 能用吗** — 不能，LT 不开放 ActiveX/COM 接口。

## 技术栈

- Python 3.12 + tkinter（GUI）
- win32com（直连 CAD COM，非 MCP 管道）
- PyInstaller（打包为独立 .exe）
- 核心算法：标准悬链线方程 + 牛顿法高差修正 + Rodrigues 旋转公式

### 模块结构（0.21 重构，单一事实来源）

| 文件 | 职责 |
|------|------|
| `catenary_core.py` | **纯算法**：悬链线 / 最小距离 / 旋转 / 分裂导线 / 悬垂串，零 CAD 依赖，可独立测试 |
| `catenary_cad.py` | **CAD 交互封装**：win32com 直连（连接 / 拾取 / 提取 / 绘制），图层颜色常量唯一出处 |
| `catenary_app.py` | 主程序：tkinter GUI + CLI（draw / mindist / wind / bundle / suspension） |
| `catenary_3d.py` | 纯算法 CLI：计算 / 导出点集（CSV / JSON），无需 CAD |
| `catenary_cad_draw.py` | 独立 COM 绘图 CLI（win32com 直连） |
| `catenary_winddev.py` | 风偏独立程序（selftest 纯数学，无需 CAD） |
| `cli_entry.py` | CLI exe 打包入口：强制命令行模式不弹 GUI（PyInstaller `--console` 用它打包 `空间弧垂曲线工具CLI.exe`） |

> 算法只在 `catenary_core.py` 一份实现，主程序与脚本统一 import，避免早期「多份副本漂移」问题。
> CAD 种类（AutoCAD / GstarCAD / 中望CAD）只在 `catenary_cad.py` 的 `_CAD_FAMILIES` 配置表一份定义（v0.23 起），连接 / 诊断 / GUI 下拉 / CLI 参数全部由它驱动。
> 同一 CAD 的多个版本实例由 `_detect_cad_instances()` 收集（v0.24 起），`foreground_cad_target()` 按前台窗口返回「CAD 种类 + 窗口句柄 + 对应 ProgID」三元组，`get_gcad(prefer, progid)` 据此精确连接。
